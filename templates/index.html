    How the image becomes a sentence

    1. Upload

    The browser sends the file to the Flask route /api/caption. The server checks that it is a real image and shrinks it to at most 1024 px.

    2. Grayscale and equalisation

    OpenCV keeps only intensity, then histogram equalisation stretches the levels so dark or washed-out photos use the full range.

    3. Blur and edge detection

    A Gaussian blur removes noise, then the Canny detector finds strong gradients. The result is the outline of objects in the scene.

    4. Model preprocessing

    For the model, the colour image is resized to 384 x 384 and normalised per channel. This is the same resize and normalise idea you study in image processing.

    5. BLIP encoder and decoder

    A Vision Transformer turns the image into feature vectors. A text decoder reads them and writes words one at a time, using beam search with 5 beams to pick the best sentence.

    6. Result

    The server sends the caption, two alternatives, the processed images and the statistics back as JSON, and this page draws them.
